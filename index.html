Developer, stack lead & problem solver.

I'm a software developer from Dhaka, Bangladesh, who loves turning messy requirements into products people actually enjoy using.

My core is Flutter for mobile, Next.js & TypeScript for the web, and Python, n8n and AI APIs for the automation in between. I care about clean architecture, honest estimates and interfaces that feel calm.

Dhaka Environment Logger

A serverless pipeline that records Dhaka's weather, air quality and UV index around the clock. GitHub Actions runs a Python logger against the OpenWeatherMap and OpenUV APIs, then commits each reading to monthly JSON and CSV files anyone can analyse. The card on the left reads that data live.

  • Scheduled GitHub Actions workflow — no server, no hosting cost
  • Logging continuously since October 2025
  • Open, monthly-rotated JSON + CSV datasets

API Monitor

Monitoring and alerting for a healthcare company's API integrations. Deterministic rules catch server errors, latency spikes and empty or malformed data; an LLM then writes the alert an on-call engineer reads — with a template fallback, so a batch never fails because of the AI.

  • One incident per API, deduplicated in MongoDB and auto-resolved on recovery
  • Batched LLM calls with strict JSON-schema output — only metrics reach the model
  • Live React dashboard, email digests and unit-tested detection rules

  • OpenAI gpt-4o-mini with JSON-schema output and a rule-based fallback
